# Bubble-Curtain-Simulation
🔗 **[Clique aqui para assistir à animação interativa](https://andreribeirorezende.github.io/Bubble-Curtain-Simulation/)**
About the simulation:
The Case A simulation illustrates two-phase flow through a bubble curtain using OpenFOAM and an innovative 8-level framework. Rendered in ParaView via alpha.water, it displays gas injected at the base forming a rising plume. As bubbles ascend, instabilities widen and fragment the plume into a turbulent cloud that spreads at the top.
